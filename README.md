# [My Awesome Future]

# Registered devlog hours on the website are not meant to be validated, they are just a way to time the amount of time each progress took.

## Description

[My Awesome Future] Is a cozy life frutiger aero inspired game, where you can talk with characters, sell and buy items, and interact with the enviroment.

## Controls

| Action | Keyboard / Gamepad |
|---|---|
| Move | [WASD / LeftStick] |
| Interact / Accept | [Mouse LeftClick / XInput A] |
| Open / Close inventory | [Tab / XInput Y] |
| Pick / Cancel Sell/Buy | [Mouse RightClick / XInput X] |
| Exit | [Esc / XInput Start] |

## What to do?

1. **Explore** Move around.
2. **Gather resources** Pick items so you can sell them or buy more.
3. **Interact with NPCs**: Talk with them. NPCs are blue, Dealers are red.
